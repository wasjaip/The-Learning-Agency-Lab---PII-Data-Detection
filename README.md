# PII Data Detection — обнаружение персональных данных в тексте

Проект по поиску PII-сущностей в текстах в рамках соревнования Kaggle **The Learning Agency Lab — PII Data Detection**.

## Задача

Определять токены, содержащие персональные данные, и корректно присваивать им соответствующие метки.

## Подход

Итоговое решение использует ансамбль из **14 моделей** на базе публично доступных DeBERTa-моделей.

Основная идея — распределять вычислительный бюджет в зависимости от длины текста:

- лучшие модели обрабатывают весь набор;
- дополнительные модели применяются к текстам с меньшей длиной последовательности;
- для разных типов PII используются разные пороги вероятности.

Это позволяет увеличить количество предсказаний там, где инференс дешевле, и уложиться в ограничение по времени выполнения.

## Постобработка

После ансамбля применяются дополнительные правила:

- проверка формата имён;
- фильтрация слишком коротких токенов;
- отдельные правила для телефонных номеров и email;
- проверка `ID_NUM` по длине и наличию последовательных цифр;
- восстановление некоторых адресных сущностей;
- обработка последовательностей `B-` / `I-`.
